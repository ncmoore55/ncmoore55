# 🚀 Flagship Project

## ☕ Project Management System — Full-Stack Java Application

The Project Management System is a full-stack application developed using **Java 21, Spring Boot, Angular, TypeScript, and PostgreSQL**.

I built this project to strengthen my software engineering skills by developing a complete application from the database and REST API to the frontend user interface.

The application allows users to create, view, update, and delete projects while monitoring project progress through an interactive dashboard.

### Completed Features

- Developed a Java Spring Boot backend
- Implemented RESTful API endpoints
- Integrated Spring Data JPA with PostgreSQL
- Created a relational database for project storage
- Built an Angular frontend using TypeScript
- Designed a black-and-gold dashboard interface
- Implemented full CRUD functionality
- Added project status tracking
- Added automatically updated dashboard statistics
- Connected Angular services to Spring Boot endpoints
- Tested API endpoints using Postman
- Used Git and GitHub for version control

### Application Architecture

`Angular Frontend → Spring Boot REST API → PostgreSQL Database`

### REST API Endpoints

**GET** `/api/projects` — Retrieve all projects

**POST** `/api/projects` — Create a new project

**PUT** `/api/projects/{id}` — Update an existing project

**DELETE** `/api/projects/{id}` — Delete a project

### Technology Stack

#### Frontend

`Angular` `TypeScript` `HTML5` `CSS3`

#### Backend

`Java 21` `Spring Boot` `Spring Data JPA` `REST APIs`

#### Database

`PostgreSQL`

#### Development and Testing

`IntelliJ IDEA` `Maven` `Postman` `Git` `GitHub` `JUnit 5`

### Key Learning Outcomes

Through this project, I gained practical experience designing REST APIs, working with relational databases, implementing CRUD operations, integrating frontend and backend applications, debugging software, and managing development through Git and GitHub.

### Future Improvements

- Expand automated unit and integration testing
- Improve input validation and error handling
- Enhance the project editing interface
- Add additional project management features
- Explore Docker containerization and cloud deployment
